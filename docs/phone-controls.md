# PocketNet 手机端操作

## 首次注册

1. 安装与树莓派服务版本匹配的 PocketNet Android APK。
2. 打开蓝牙和 Wi-Fi。
3. 在手机注册页面扫描本机生成的永久二维码。
4. 通过 BLE 完成设备身份验证和注册。
5. 确认系统添加 PocketNet 管理热点。
6. App 使用注册返回的 CA 证书和 per-device token 连接 gRPC Telemetry 服务。
7. 首次收到有效快照后，仪表盘显示实时系统和无线观测状态。

注册信息安全保存在手机系统安全存储中。普通重启不需要重新扫码；全新烧录会生成新的设备身份和二维码，旧手机需要重新注册。

## 仪表盘与消息

- 仪表盘通过 gRPC Server Streaming 接收状态快照，默认每 3 秒更新。
- 突发事件在服务端提交后立即推送。
- 消息中心将事件与游标写入手机 SQLite。
- 手机断线时，树莓派继续采集并保留有界事件历史。
- 重连后从最后成功持久化的游标恢复。
- 数据字段缺失或过期时显示“未报告”或数据年龄，不将未知显示为零或安全通过。

## BLE 校时

从构建 19 起，每次 App 建立实时遥测连接时，自动使用 BLE 验证并检查已注册树莓派的时间。偏差不超过 500 毫秒时保留现有时钟，树莓派明显落后时自动校准。树莓派超前超过 500 毫秒时，在设备菜单打开「蓝牙校时」确认回拨。蓝牙未就绪或 App 处于后台时，实时遥测仍可使用，后台连接可在返回前台后补做校时。点击顶部连接状态可查看自动校时结果，也可继续用设备菜单手动校时。BLE 注册与校时可离线执行。

## 注册设备数量限制

每台 PocketNet 最多允许 5 台处于 active 或 revoking 状态的手机。已注册手机恢复连接不占用新名额；撤销流程完成、热点凭证已禁用且状态变为 revoked 后，名额才释放。正在撤销但热点凭证尚未禁用的设备仍占用名额。
