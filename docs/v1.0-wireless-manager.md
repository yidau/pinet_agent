# V1.0 外接 USB 无线观测

内置无线网卡只负责 PocketNet 管理热点。外接 USB 网卡由用户明确绑定，持续作为 Kismet 的 Monitor Mode 数据源。树莓派端没有 MCP Server；C++ Telemetry 服务通过 gRPC/Protobuf 与手机通信。

## 设备绑定

在树莓派上由设备所有者亲自检查实际硬件：

```bash
uname -m
cat /etc/os-release
lsusb
iw dev
iw phy
ip -br link
```

从 `iw dev` 中选择外接 USB 无线接口，读取设备身份：

```bash
MON_IF=<当前外接网卡接口>
udevadm info --query=property --path="/sys/class/net/$MON_IF" | \
  grep -E '^(ID_BUS|ID_PATH|ID_VENDOR_ID|ID_MODEL_ID|ID_NET_DRIVER)='
readlink -f "/sys/class/net/$MON_IF/phy80211/device"
```

将已核实的 VID、PID、USB 物理端口、驱动和当前接口传给配置脚本：

```bash
sudo python3 raspberry/config/kismet/configure_monitor.py \
  --interface "$MON_IF" --vendor "$MON_VID" --product "$MON_PID" \
  --port "$MON_PORT" --driver "$MON_DRIVER"
sudo udevadm control --reload
```

脚本将设备绑定到固定名称 `pn-wifi0`，验证它与 hostapd 管理热点使用不同 PHY，并安装独立的 systemd datasource manager。配置只允许已绑定的 USB 设备，不会回退使用内置热点网卡。

## Kismet 采集策略

Kismet 是唯一的原始无线采集引擎。受管 datasource definition 固定包含：

```text
pn-wifi0:type=linuxwifi,name=PiAgent USB monitor,uuid=<固定 UUID>,vif=pn-wifi0mon,retry=false,filter_mgmt=true
```

`filter_mgmt=true` 是 Linux Wi-Fi datasource 的捕获过滤参数，保留 802.11 管理帧和 EAPOL，过滤普通数据帧。它不是按 BSSID 过滤，也不表示网卡硬件不再接收其他帧。该模式下的 PPS 是过滤后被观测到的帧速率，不代表完整 WLAN 吞吐。依赖普通数据帧的统计应显示不可用，而不是零。

Kismet 服务持续运行。Datasource manager 在外接网卡可用时创建或恢复固定 UUID 的数据源；拔卡时关闭受管数据源并报告降级；插回同一设备后恢复。它不启动第二个 Kismet 实例，不创建 managed scan，也不使用管理热点网卡作为监听回退。

## 启动与验收

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now piagent-kismet.service piagent-wireless-manager.service
systemctl is-active piagent-hotspot.service piagent-kismet.service piagent-wireless-manager.service
iw dev
cat /run/piagent-wireless/monitor.json
journalctl -u piagent-wireless-manager.service -u piagent-kismet.service -b -n 60 --no-pager
```

验收时由设备所有者确认：

1. 手机管理热点正常，且与 `pn-wifi0` 使用不同 PHY。
2. Kismet datasource 为受管 USB 网卡，定义中包含 `filter_mgmt=true`。
3. 实际收到 Beacon、Probe、认证管理帧和 EAPOL。
4. 拔掉外接网卡后热点仍然可用，采集状态变为降级。
5. 插回同一 USB 端口和设备后，原 UUID 数据源恢复。
6. 现场记录 Kismet 队列丢包、系统资源与观测覆盖。队列零丢包不等于空口零遗漏。

不要将扫描、回放或其他数据源的告警自动归因为当前实时 monitor 网卡。来源无法证明时，应标记为 Kismet 实例级来源。
