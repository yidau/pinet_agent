# V0.3 独立热点凭据

注册服务为每台手机生成独立的随机 WPA2 passphrase。`hostapd` 通过 `wpa_psk_file` 为同一个 SSID 加载这些凭据，并用设备的凭据 ID 标记对应条目。条目允许任意站点 MAC 使用自身持有的凭据，因此手机启用或更换私有 MAC 后仍能连接。设备的 BLE 和 API 身份由注册公钥验证。[hostapd 的 PSK 文件格式](https://android.googlesource.com/platform/external/wpa_supplicant_8/+/refs/heads/master/hostapd/hostapd.wpa_psk)

撤销时，服务先持久化删除对应条目，再请求 `RELOAD_WPA_PSK`。hostapd 2.10 根据已协商的 PMK 选择性断开失去对应密码的站点，其他使用有效密码的已连接站点继续工作。若控制接口暂不可用，辅助服务返回 Wi-Fi 撤销未确认，并重试加载。磁盘上已删除的凭据在下次启动热点时失效。[hostapd 2.10 控制接口源代码](https://chromium.googlesource.com/chromiumos/third_party/hostap/+/refs/heads/firmware-ec-R140-16371.2.B-wpa_supplicant-2.10.0/hostapd/ctrl_iface.c) · [上游多 PSK 和选择性断开测试](https://chromium.googlesource.com/chromiumos/third_party/hostap/+/33c4de221b090a870ad0df95ee426dc399927b10/tests/hwsim/test_ap_psk.py)

## 迁移现有 PiAgent 热点

通过有线 SSH 进行首次迁移。切换时重启现有热点会中断 Wi-Fi 连接。新凭据表初始为空，手机完成 BLE 注册后才能用其独立凭据重新加入同名热点。

```sh
sudo install -d -o root -g root -m 0700 /var/lib/piagent-enrollment
sudo test -e /var/lib/piagent-enrollment/hostapd.psk || \
  sudo install -o root -g root -m 0600 /dev/null /var/lib/piagent-enrollment/hostapd.psk
```

在 `piagent-hotspot.service` 使用的 `/etc/hostapd/piagent.conf` 中设置下列选项。保留现有国家代码、信道和其他射频参数。删除此前的 `wpa_passphrase` 或 `wpa_psk` 条目。该服务面向 `wlan0` 上的单个 PiAgent 热点，WPS、RADIUS PSK、快速漫游和 PMKSA 缓存保持关闭。

```ini
interface=wlan0
driver=nl80211
ssid=PiAgent
ctrl_interface=/run/hostapd
ctrl_interface_group=0
wpa=2
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP
wpa_psk_file=/var/lib/piagent-enrollment/hostapd.psk
disable_pmksa_caching=1
```

从仓库根目录安装辅助程序和 systemd 单元。系统应已有 V0.2 创建的 `piagent-ble` 用户。配置及其安装路径由 root 管理。

```sh
sudo install -d -o root -g root -m 0755 /opt/piagent-enrollment/raspberry/enrollment
sudo install -o root -g root -m 0644 raspberry/enrollment/wifi_helper.py \
  /opt/piagent-enrollment/raspberry/enrollment/wifi_helper.py
sudo install -o root -g root -m 0644 raspberry/config/enrollment/piagent-enrollment-wifi.socket \
  raspberry/config/enrollment/piagent-enrollment-wifi.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl restart piagent-hotspot.service
sudo systemctl enable --now piagent-enrollment-wifi.socket
```

辅助程序经 `/run/piagent-enrollment-wifi.sock` 接受 `piagent-ble` 用户的 `set` 和 `revoke` 操作。所有 PSK 留在权限为 `0600` 的文件或注册所需的进程内存中，辅助程序日志仅记录结果。硬件验收需要用注册后的手机实测接入和选择性断开，由 hostapd 执行 WPA2 握手。
